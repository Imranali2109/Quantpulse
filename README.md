# QuantPulse

AI-powered stock analysis and market intelligence platform.

## Features

- Real-time stock data
- Technical indicators
- Momentum analysis
- Volatility analysis
- Trend analysis
- Convergence scoring
- Street Sheet
- Watchlist
- Signal history
- Market analysis
- India and US market support

## Tech Stack

Frontend:
- React
- TypeScript
- Vite
- Tailwind CSS

Backend:
- Node.js
- Express
- TypeScript

Data:
- Yahoo Finance
- SQLite

AI:
- Google Gemini
- Tavily

## Getting Started

npm install

Create .env.local

npm run dev
